# Installation

## Stable release

To install care_sast, run this command in your terminal:

```sh
pip install care_sast
```

## From source

The source files for care_sast can be downloaded from the [Github repo](https://github.com/10bedicu/care_sast).

You can either clone the public repository:

```sh
git clone git://github.com/10bedicu/care_sast
```

Or download the [tarball](https://github.com/10bedicu/care_sast/tarball/master):

```sh
curl -OJL https://github.com/10bedicu/care_sast/tarball/master
```

Once you have a copy of the source, you can install it with:

```sh
cd care_sast
pip install .
```
